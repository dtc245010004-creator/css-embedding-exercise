Bài tập: 3 Cách nhúng CSS vào trang HTML

Tiêu đề: Học lập trình Web

Đây là đoạn văn bản được đổi màu xanh dương bằng Inline CSS trực tiếp trong thuộc tính style của thẻ.

Phần 2: Sử dụng Internal Style (thẻ <style> trong phần <head>)

Tiêu đề: Ngôn ngữ định kiểu CSS

Đây là đoạn văn bản được đổi màu đỏ thông qua class được định nghĩa trong thẻ style ở phần head.

Phần 3: Sử dụng External Style (liên kết tới file style.css bên ngoài)

Tiêu đề: Tách biệt cấu trúc và giao diện

Đây là đoạn văn bản được đổi màu xanh lá bằng các class viết trong file style.css riêng biệt.
